Un agent d’achat est un intermédiaire, pas une boutique

LitBuy ne vend pas la marchandise. Il achète pour toi dans des boutiques chinoises qui n’expédient pas à l’étranger, photographie à l’entrepôt, stocke, puis tu livres vers la France.

Ça change tout : tu paies deux fois (marchandise + domestique Chine, puis la ligne internationale), tu attends deux fois, et tu peux regrouper ou changer de SKU entre les deux. Ce host litspreadsheet.fr est un desk indépendant, pas le site officiel. Destination France, pas la Belgique.

Un spreadsheet n’est pas un fichier Excel

Ici, « spreadsheet » n’est pas un tableau de lignes : c’est un catalogue de fiches avec photo, marque, prix de référence et le lien que l’agent peut ouvrir.

L’index de cette accueil est anglais (sneakers, hoodie, jacket). « Baskets » renvoie souvent zéro carte ; sneakers remplit la grille. Les milliers de finds restent sur w2clinks — on ne les verse pas dans un .xlsx.

Beaucoup de fiches ne s’achètent pas, même affichées

Sur le site officiel, des fiches « Restricted item » ou à prix zéro. Ce n’est pas un bug : le lien source n’est pas achetable par l’agent, ou le prix n’a pas pu être lu.

Pas de prix ni d’options réels : n’en compte pas. Tabac, alcool, médicaments sont souvent refusés — la liste est dans l’aide officielle, on ne l’invente pas. Pas de sous-déclaration.

Questions

LitBuy vend-il la marchandise ?

Non. C’est un agent : il achète en Chine, photographie, tu paies la ligne internationale ensuite.

Où est le catalogue ?

Sur cette accueil, via /api/products/ de ce host. Les 8 000 finds restent sur w2clinks.

La destination est-elle « EU » ?

Non. L’estimateur veut un pays. Ici : France. Les dossiers Belgique de ce host ne définissent pas la France.

Les coupons ?

L’article /litbuy-coupons/ liste les codes du compte. Vérifie dans My Coupons. Pas dans ce title.

Invite dans le title ?

Non. Le code d’affiliation est sur le bouton Register, pas dans <title>.

Stockage ?

Help Center officiel : 90 jours gratuits depuis stocked/listed, plafond 120.

Poids volumétrique ?

L×W×H/8000 (kg) sur beaucoup de lignes aériennes. Le widget ci-dessus n’est pas un devis.

Douane ?

Suit la SKU. Pas de conseil de sous-déclaration. Sources officielles le matin de l’envoi.

Ce host est-il litbuy.com ?

Non. Desk indépendant.

301 vers now.com ?

Non. Les TLD du même agent restent séparés.

Photos QC ?

Dans l’app, après arrivée entrepôt.

Deux paiements ?

Oui : marchandise + domestique Chine, puis fret international.

USD vs EUR ?

L’affichage officiel peut rester en USD. Lis le montant, pas seulement le symbole.

Avis déjà classé ?

Oui — /litbuy-review/ n’est pas écrasé.

Espagne 58 lignes ?

Non. Les lignes ES restent un autre desk.
