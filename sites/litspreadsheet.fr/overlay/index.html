Questions

LitBuy vend-il les produits sur ce site ?

Non. LitBuy est agent d’achat. Commandes et paiements uniquement sur litbuy.com.

Puis-je payer ici ?

Non. Paiement sur litbuy.com. Affichage EUR. Fret live: https://litbuy.com/shipping-estimate destination France.

Quel pays dans l’estimateur ?

France — pas ce TLD, pas EU, pas Belgique. code postal français (form 75001).

Le QC se fait-il chez Colissimo ?

Non. Photos prises en Chine. La Poste est last-mile après QC.

Qui paie la douane ?

La SKU. Source: https://www.douane.gouv.fr/ (douane FR). Cette page n’invente pas de valeur déclarée.

La Belgique est-elle la même SKU ?

Non. Un code postal belge est le mauvais pays.

Pourquoi le catalogue ne trouve rien en français ?

L’index est anglais (sneakers, hoodie, jacket).

Où est le code d’invitation ?

Pas dans ce titre. Les URL coupon sur litspreadsheet.fr restent.
