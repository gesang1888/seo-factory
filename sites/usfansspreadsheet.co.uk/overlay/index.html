HMRC / import — educational only

UK import VAT and any duty follow the carrier product you actually buy and the facts of the shipment. HMRC and the carrier set that, not a spreadsheet cell. This desk does not pick a declared value, and it does not coach under-declaration.

If a line is sold as tax-prepaid / DDP-style, that is still a specific SKU in USFans. If it is not, expect the last-mile operator to handle import on their terms. Read the live product description in the app after packing.
