Questions

Puis-je mettre un code belge ?

Non. France — code postal à cinq chiffres, pas un code belge. Dernier km souvent Colissimo.

Où payer ?

Sur orientdig.com. Calculateur : https://orientdig.com/estimation/ destination France.

Quand réserver le fret ?

Après les photos QC. Durée d’entrepôt dans la Help de orientdig.com.

Qui paie la douane ?

La SKU. Source : https://www.douane.gouv.fr/ (douane.gouv.fr). Cette page n’invente pas de valeur déclarée.
