How a PikoBuy order actually runs

PikoBuy is a purchasing agent, not a shop. You paste a product link from Taobao, 1688, Weidian or Yupoo. They buy, photograph, store, then you book an international line. pikospreadsheets.net never takes a card. Official checkout is pikobuy.com.

The official shopping guide on 8 Oct 2026 spelled the path as: select items → search/paste a link → first payment → warehouse inspection (check-in, photo confirmation, defect check) → pay international shipping → tracking within 3 days of dispatch. Returns protocol the same day: a 5-day in-warehouse window when the seller still allows resale. This desk does not invent a free-storage ladder.

This .net host is independent of pikospreadsheet.com and pikobuyspreadsheet.com — no 301 between them. Freight still comes from pikobuy.com after warehouse photos. This desk does not coach customs values and does not reprint a 58-line Spain snapshot.
