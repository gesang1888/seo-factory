More ways to save with FSBuy

  • Consolidate shipments — ship multiple items together. One DHL parcel with 3 items beats three separate orders every time.
  • Use economy shipping lines — Economy Line A costs 55–65% less than DHL with only 1–2 extra weeks. See our shipping guide.
  • Rehearsal packaging — ask your agent to repackage items without original boxes to reduce volumetric weight.
  • Compare agent welcome packs — new-user coupons differ by agent. Register through the agent you plan to use most.

How do I use a FSBuy coupon code?
Copy the code from this page, go to FSBuy checkout, find the Coupon Code field, paste your code and click Apply. The discount appears in your order summary before payment.
Can I stack multiple coupon codes?
Generally only one coupon code can be applied per order. However, order discount codes and shipping discount codes are sometimes treated separately — meaning you may be able to apply one of each.
