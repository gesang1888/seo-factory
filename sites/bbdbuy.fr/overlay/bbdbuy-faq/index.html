FAQ BBDBuy pour acheteurs en France (2026)

FAQ spreadsheet BBDBuy France sur bbdbuy.fr : index, QC, Colissimo / La Poste, douane.gouv.fr.

Ce site vend-il ?

Non. Commandes sur www.bbdbuy.com. bbdbuy.fr liste les finds pour la France.

Spreadsheet ?

Shortlist pour code postal français à cinq chiffres. Pas Excel. Keywords: bbdbuy spreadsheet france.

QC

Photos in-app en Chine.

Colissimo / La Poste ne refait pas la photo.

Livraison France

Estimateur FR, souvent Colissimo / La Poste, https://www.bbdbuy.com/estimation. Pas de délais inventés.

Droits

La SKU. Collect extra. https://www.douane.gouv.fr/. Pas de sous-déclaration.

EUR ici

Affichage. Caisse www.bbdbuy.com.

Code belge ?

Non. Mauvais pays.

Inscription

Seulement www.bbdbuy.com.

Puis-je mettre un code belge ?

Non. France — code postal français à cinq chiffres. Un code postal belge à quatre chiffres est le mauvais pays. Dernier km souvent Colissimo / La Poste.

Destination France dans https://www.bbdbuy.com/estimation. Un código español n’est pas cette page.

Où payer ?

Sur www.bbdbuy.com. bbdbuy.fr montre des finds en euro ; la caisse, le portefeuille et les tickets restent sur le site officiel.

Fret live : calculateur https://www.bbdbuy.com/estimation destination France.

Quand réserver le fret ?

Après les photos QC dans l’app. Colissimo / La Poste ne refait pas une photo d’entrepôt une fois le carton en France.

Durée d’entrepôt dans la Help de www.bbdbuy.com. Lis-la le matin de l’envoi.

Qui paie la douane ?

La SKU réservée. Colissimo / La Poste peut ajouter un Collect que l’estimateur ne montre pas.

Source : https://www.douane.gouv.fr/ (douane.gouv.fr). Cette page n’invente pas de taux ni de valeur déclarée.

Les clés anglaises (sneakers, hoodie) sont-elles une boutique BE ?

Non. Le mur catégories est anglais parce que l’index est anglais. « Baskets » ou « sweat » donnent souvent zéro carte.

Le pays de l’estimateur reste la France. Ces clés ne changent ni la douane ni le dernier km.

Deux paiements — c’est une erreur ?

Non. Marchandise vers la Chine d’abord, fret international après QC. Deux reçus dans l’app sont normaux.

Si l’app facture une seule fois, l’app gagne. www.bbdbuy.com.

Faut-il ce spreadsheet ?

Non. Tu peux chercher dans l’app officielle. La feuille évite les cartes Weidian mortes vers une porte en France.

bbdbuy.fr ne voit pas le compte. Inscription seulement sur www.bbdbuy.com.

Une boîte belge, c’est la même SKU ?

Non. Un code belge à quatre chiffres est un autre pays dans l’estimateur. code postal français à cinq chiffres est le test d’adresse de ce desk.

Confirme destination France dans https://www.bbdbuy.com/estimation le matin de l’envoi.
