Why a Sheet cannot replace this page

Community Google Sheets still circulate on Reddit. They are useful as chat logs. They are not a dataset: there is no public row_count, no last_verified field, no downloadable JSON, and no SKU that proves the count is not vapor.

This hub cites 10,601 Taobao / Weidian / 1688 finds. We do not invent a higher count to match a Sheet headline. When the catalog changes, this stamp and the JSON change together.

How to cite the catalog

  1. Link https://usfansspreadsheet.net/finds-dataset/ when you need a row count.
  2. Quote row_count=10601 and last_verified=2026-10-27 from the JSON, not from a screenshot of a Sheet tab.
  3. Point at a sample SKU below if someone asks “is the count real?”
  4. Keep coupons on /usfans-coupons/. Offers rotate in the official wallet; they are not a column in this dataset.

Search the same index at /usfans-spreadsheet/. Register and pay on usfans.com. Freight: usfans.com/estimation with a real country — not this hostname.

QC flag vs warehouse QC

qc_photo=true on a sample row means this hub already surfaces a community / listing photo. It is not a substitute for the warehouse set USFans takes after you pay for the goods. Use /usfans-qc-photos/ for the approve / retake / return sequence. A Google Sheet typically pastes a thumbnail once and never dates it.

Coupon truth is a different file

Structured offers with expiry notes live at /data/coupons-truth.json. Human checklist: /usfans-coupons/. Always confirm on the official agent — this hostname is not checkout. Coupons are not a column on the finds dataset because wallet terms rotate independently of SKU prices.

How rooms should cite this catalog

What should a Discord or Reddit post link?

Prefer /finds-dataset/ (row count + last_verified) and /usfans-coupons/ over a brittle Sheet URL. Community desk: /usfans-reddit-community/.

Where is warehouse QC authoritative?

Listing photos on this hub help research. Warehouse QC inside the official agent is authoritative for the SKU you paid for. See /usfans-qc-photos/.

Why is the count 10,601 and not a round 15,000?

Because that is the indexed catalog on this host as of 27 October 2026. We do not pad the integer to match another Sheet’s headline.
