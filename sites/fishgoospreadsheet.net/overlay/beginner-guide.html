FishGoo: album → remarks → QC shots

  1. Open FishGoo and create the account on their site/app.
  2. Paste the Yupoo / Weidian / 1688 URL. In remarks, write size, colorway, and the album page number.
  3. If the seller uses a code (M, L, 42.5), copy it exactly. Do not convert to US sizes in the remarks.
  4. When QC lands, check tag + measurement + defect close-up.
  5. Ship from FishGoo's own line list. Keep bills; they are how you debug a seized parcel later.
