FishGoo workflow for mixed Yupoo / Weidian / 1688 hauls

FishGoo users usually do not start from a Taobao search box. They start from a Yupoo album or a Weidian shop, then ask the agent to turn a lookbook into a payable cart. This hub is that translation layer — not a copy of a shared W2C catalog.

Reddit threads help you learn the QC vocabulary (GL/RL). They do not replace FishGoo's own order form. If an album has no SKU, you still owe FishGoo a measurable size and a colorway string.
